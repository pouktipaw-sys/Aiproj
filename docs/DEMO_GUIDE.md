# Recruiter demo guide (3–5 minutes)

1. Explain the goal: passive, scoped observations.
2. Show tests that reject an external hostname by default.
3. Run: python -m web_attack_surface_lab demo --output reports/demo
4. Open reports/demo/report.md and explain one observation.
5. Open reports/demo/report.json and explain structured output.
6. State limitations: this is not a full vulnerability scanner; findings need manual validation.

Do not scan a company, recruiter or public service without explicit written authorization. Use the synthetic demo for a portfolio walkthrough.
